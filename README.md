# REGLET Studio

Онлайн-конструктор печатной продукции в стиле CorelDRAW. Один экран: холст с линейками в мм, панель заказа с расчётом цены, preflight, 3D-мокап и генератор печатного PDF.

## Структура

```
index.html          разметка интерфейса
css/app.css         текстуры материалов, стили CorelDRAW и пейстаборд
js/config.js        продукция, материалы, тарифы, локальные шрифты PDF
js/templates.js     6 готовых шаблонов визиток
js/state.js         состояние, история undo/redo, тосты
js/pricing.js       расчёт цены и совместимость отделки
js/preflight.js     проверка макета перед печатью
js/canvas.js        рендер холста, линейки, drag/resize/rotate
js/mockup.js        3D-мокап изделия
js/pdf.js           экспорт PDF 1.4 (клип по листу, кривые, crop marks)
js/ui.js            докеры, слои, инспектор, все обработчики
js/main.js          точка входа
assets/fonts/       локальные TTF для PDF: латиница + кириллица, 4 начертания
```

## Запуск

Только через статический сервер: PDF-шрифты загружаются через XHR и не работают с `file://`.

```bash
python -m http.server 8000 --directory D:\MyProject\RegletStudio
```

Открыть `http://localhost:8000`.

## Рабочая область и экспорт

- Рабочая область — лист изделия с вылетами. Объекты за пределами листа (на пейстаборде) видны, выделяются и редактируются, но в PDF не попадают.
- Экспорт обрезается ровно по листу; метки реза и `TrimBox` сохраняются.
- Текст в PDF переводится в кривые локальными шрифтами. В файле нет `/Font` и текстовых операторов, поэтому шрифты не подменяются и не сбиваются.
- Превью и 3D-мокап показывают область реза.

## Зависимости

- Tailwind CSS (CDN)
- opentype.js 1.3.4 (CDN)
- Google Fonts для интерфейса (CDN)
- Локальные TTF в `assets/fonts` (SIL OFL 1.1) для экспорта PDF
